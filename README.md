One line, chosen to stop the scroll: "I waved back at a mannequin in a shop window today, and the worst part is that the mannequin started it." A tiny Node program writes that single line — 104 characters, one sentence, turn in the final clause — to the entry file. The line was picked by an adversarial criteria critique over nine rival candidates (strongest on the scroll-stopping opening and on genuine, not merely clever, entertainment), and the program guards the gate itself: 1–240 characters, a single line, never only whitespace.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
